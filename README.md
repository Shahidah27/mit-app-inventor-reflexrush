# 📱 ReflexRush - Educational Quiz App

A mobile quiz application built using **MIT App Inventor** featuring timed scoring mechanics and persistent local data storage via **TinyDB**.

---

## 📦 Files Included

* **`ReflexRush.aia`** - Source code file. Import this into MIT App Inventor to inspect or modify the design and block logic.
* **`ReflexRush.apk`** - Installable Android package. Download directly onto an Android device to test the app.

---

## 🛠️ Features & Tech Stack

* **Platform:** MIT App Inventor (Event-driven block programming)
* **Storage:** TinyDB (Local persistent data storage for scores)
* **Features:** Timed quiz mechanics, interactive feedback, and local high-score tracking.

---

## 🚀 How to Use / Import

### To Edit Code in MIT App Inventor:
1. Download the `.aia` file from this repository.
2. Go to [MIT App Inventor](https://ai2.appinventor.mit.edu/).
3. Log in and select **Projects** > **Import project (.aia) from my computer...**
4. Select the downloaded `.aia` file.

### To Install on Android Device:
1. Download the `.apk` file directly to your Android device.
2. Open the file and allow installation from unknown sources if prompted.
